# シェリングの分居モデル — Interactive Lab

Thomas Schelling の segregation model（分居モデル）を、ブラウザ上で操作しながら理解するための教材です。

## 構成

- `index.html` — セマンティックな画面構造
- `styles.css` — レスポンシブUI
- `js/model.js` — シミュレーションの純粋なモデルロジック
- `js/app.js` — DOM・Canvas・操作イベント
- `js/chart.js` — 履歴グラフ描画
- `tests/model.test.mjs` — モデルの基本テスト
- `package.json` — ローカルテスト／簡易サーバー用

## 実装しているモデル

各セルは A、B、空き地のいずれかです。住民は指定された近傍にいる「住民」のうち、自分と同じグループの割合を計算します。空き地は割合の分母に含めません。同類率が閾値未満なら不満と判定されます。

移動ルールは2種類あります。

1. **満足できる空き地へ** — 閾値を満たせる空き地からランダムに選択。候補がなければ移動しません。
2. **ランダムな空き地へ** — 空き地をランダムに選択。移動後も不満な場合があります。

各ラウンドでは、開始時点で不満な住民の順番をランダム化し、処理時点でも不満なら逐次移動させます。

## 主な機能

- 満足閾値、グリッドサイズ、空き地率、A/B比率を変更
- Moore近傍 / von Neumann近傍
- 通常境界 / トーラス境界
- 2種類の移動ルール
- seedによる初期配置の再現
- 1ラウンド実行 / 自動再生
- 満足率・平均同類率・不満人数・移動数を表示
- 満足率と平均同類率の履歴グラフ
- 住民をクリックして近傍・同類率・満足判定を確認
- モバイル対応

## ローカル実行

ES Modules を利用しているため、`file://` 直開きではなくHTTPサーバー経由で開いてください。

```bash
npm run serve
```

その後 `http://localhost:8000` を開きます。

## テスト

```bash
npm test
```

テストでは seed の再現性、人口・空き地数の保存、同類率計算、孤立住民の扱い、近傍定義を確認しています。

## 注意

このモデルは社会現象を単純化した説明モデルです。現実の居住分離には所得、住宅価格、制度、歴史的差別、交通、家族構成など多数の要因があります。
