# Urban Lab V2

ブラウザだけで動く、エージェント型の都市シミュレーションです。単なる色付きグリッドではなく、道路ネットワーク・住宅市場・雇用・通勤交通・公共サービス・財政・政策が相互作用します。

## 主なモデル

- 36×36グリッド
- 道路ネットワークの連結成分を計算し、道路未接続地区は発展しない
- 住宅 / 商業 / 工業 / オフィスは「用途指定」後、需要に応じて民間が自動開発・高密度化
- 世帯エージェントに世帯人数、就業者数、教育水準、所得、居住地、勤務地、満足度を保持
- 雇用容量を厳密に守りながら道路で到達可能な勤務地へマッチング
- 実際の最短道路経路へ通勤交通を流し、道路ごとの交通負荷を計算
- 駅近接の出発地・勤務地では公共交通を利用し、自動車交通を削減
- 地価は道路接続、公園、学校、病院、駅、商業利便性、汚染、交通負荷から算出
- 家賃は地価、建物レベル、入居率から算出
- 世帯満足度は所得、家賃負担、雇用、通勤、地価、汚染、公共サービス、税率から算出
- 低満足・失業世帯は転出。需要と空室があれば新規世帯が転入
- 市財政は所得税、固定資産税、道路・施設維持費、政策支出から月次計算
- 公共交通補助、住宅費補助、環境規制の3政策
- 景気拡大、景気後退、大気停滞、人口流入などの外生イベント
- 土地利用 / 交通 / 地価 / 汚染 / 幸福度レイヤー
- 48期間トレンドグラフ
- ミッション、イベントログ、ローカル保存 / 読込

## 操作

1. 道路を敷く
2. 道路沿いに用途地域を指定する
3. 再生すると需要に応じて民間開発が進む
4. 学校・病院・公園・駅を配置し、地価・幸福度・交通を調整する
5. 税率と政策を変え、人口増加と財政の両立を目指す

外部ライブラリは使用していません。
