## 操作
「次の気づき」で同じ章の観察・理由・結果を順に表示します。章末では次の解答欄へ進みます。上部のタブから各章へ移動できます。D付近は等縮尺で拡大できます。体積の章ではACを軸に0〜90度折り曲げられます。立体をドラッグして視点を変更でき、「真上」「折り目の方向」でも確認できます。

## 数学上の修正
旧版の非等方スケールを廃止し、平面図の縦横倍率を統一しました。円と交点、内心I、二等分線、直角記号・等角の弧を同一座標モデルから生成します。AG:GB=5:3は長さそのものではなく比として表示します。

CEは二等分線の長さの公式に頼らず、AE=3CEと三平方で計算します。最後の体積には、底面積21/8と高さ3√10/5を使います。折り曲げ途中のDF′は高さではなく、高さはDF×sinθです。∠BDF′=180°−θを表示し、θ=90°で初めてDF′が高さになります。
