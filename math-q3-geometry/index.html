図形の関係が見えるように、各ステップを 図 + 最小限の式 で整理したページです。 単なる文字解説ではなく、なぜそう見えるのか を追える構成にしています。

STEP 1

基本図形を座標で見る

まず図形を見やすくするために、B=(0,0), C=(2,0), A=(0,6) とおくと、 △ABC は直角三角形になります。 線分 BC を直径とする円と AC の交点が D です。

AC = √(6² + 2²) = √40 = 2√10

また、AB は円への接線なので、方べきの定理より AB² = AD・AC

36 = AD・2√10 より AD = 9√10 / 5

したがって CD = AC - AD = √10 / 5

STEP 2

点Eは「角の二等分線」で決まる

条件 ∠BAE = 2∠BAC から、AC は △ABE における ∠BAE の二等分線です。 しかも C は辺 BE 上にあります。

角の二等分線の定理より BC : CE = BA : AE

2 : CE = 6 : AE より AE = 3CE

さらに角の二等分線の長さの公式 AC² = AB・AE - BC・CE を使うと

40 = 6AE - 2CE = 18CE - 2CE = 16CE

よって CE = 5 / 2、したがって AE = 15 / 2

STEP 3

点Fでは「合同」が見える

F は直線 BD と直線 AE の交点です。ここで D は AC 上にあるので、 ∠BAD = ∠BAC です。また ∠DAF = ∠BAE - ∠BAC = ∠BAC となるため、 ∠BAD = ∠DAF が成り立ちます。

D は直径 BC の円周上にあるので ∠BDC = 90°

A, D, C は一直線上だから ∠BDA = 90°

さらに B, D, F は一直線上より、∠ADF = 90°

よって △ABD と △AFD は、

∠BAD = ∠DAF、∠BDA = ∠ADF、AD 共通 で合同

したがって BD = DF。B-D-F が一直線なので FB = BD + DF = 2DF

つまり DF / FB = 1 / 2

STEP 4

内心Iから点Gの比を読む

I は △ABE の内心なので、EI は ∠AEB の二等分線です。 その EI と AB の交点が G です。

EB = BC + CE = 2 + 5/2 = 9/2

角の二等分線の定理より AG : GB = AE : EB

= 15/2 : 9/2 = 5 : 3

よって AG / AB = 5 / (5+3) = 5 / 8

STEP 5

折り曲げた後は「底面積 × 高さ」

AC に沿って折り曲げると、F は F′ に移ります。問題の条件より ∠BDF′ = 90°。 もともと D は AC 上にあり、DF は AC に垂直な方向として見られるため、折り曲げ後の F′D は 底面 BCDG に垂直な高さとみなせます。

△BCD は直角三角形なので

BD² = BC² - CD² = 4 - 2/5 = 18/5

よって BD = 3√10 / 5

合同より DF = BD = 3√10 / 5。したがって高さも 3√10 / 5

底面積は [BCDG] = [BCD] + [BDG] = 3/5 + 81/40 = 21/8

よって体積

V = (1/3) × (21/8) × (3√10/5) = 21√10 / 40

この問題の見どころ

  • 接線と円 → 方べきの定理で CD を出す
  • ∠BAE = 2∠BAC → AC が角の二等分線だと見る
  • 合同 → △ABD ≡ △AFD から DF / FB = 1 / 2
  • 内心 → EI が角の二等分線だから AG / AB を一発で出せる
  • 折り曲げ → 3D に見えても最後は底面積と高さ
